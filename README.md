# E-Commerce Sales & Performance Dashboard

## 📊 Project Overview

An end-to-end E-Commerce Sales Analytics project developed using
Excel, SQL, and Power BI to analyze sales, profit, products,
regions, payment methods, and order performance.

## 🛠️ Tools & Technologies

- Microsoft Excel
- SQL Server
- Power BI
- Power Query
- DAX

## 🔄 Project Workflow

Excel Data
→ SQL Server
→ SQL Analysis
→ Power BI
→ DAX
→ Interactive Dashboard
→ Business Insights

## 💡 Key Insights

- Electronics generated the highest category sales.
- South region recorded the highest regional sales.
- UPI was the highest sales-generating payment method.
- Accessories showed the highest category-level profit margin.
- Smartphone was the highest-selling product among the displayed products.
